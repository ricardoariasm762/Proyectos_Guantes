- fkgaos39djmre5yjxfuenl578kv (pasos_completados -> intentos_practica)

Al intentar eliminar un usuario con registros asociados, la BD arrojaba:
"ERROR: update o delete en «usuarios» viola la llave foránea «fkl5p8og4xym3mkqwofipoik5fb» en la tabla «intentos_practica»".

RESOLUCIÓN Y APLICACIÓN DE MIGRACIÓN:

ALTER TABLE intentos_practica DROP CONSTRAINT fkl5p8og4xym3mkqwofipoik5fb;
ALTER TABLE intentos_practica ADD CONSTRAINT fkl5p8og4xym3mkqwofipoik5fb FOREIGN KEY (usuario_id) REFERENCES usuarios(id) ON DELETE CASCADE;

ALTER TABLE progresos DROP CONSTRAINT fk3rdrf36k70chrnbuskgd8y9tq;
